# OpenScope Android 0.4.6 本地验收

0.4.6 修复 B 站官方电脑网页在手机模式下的视频页：原页最小宽度约 1080 CSS 像素，导致标题和播放器横向裁切；下滑后播放器进入 `mini` 固定定位，覆盖评论。现在视频与信息按手机宽度排成单列，滚动时 `mini` 播放器保持在原文档位置，不遮挡下方内容。

视频页顶部加入“全屏”。点击后切换横屏、隐藏系统栏与站点导航，视频按比例居中播放；“退出全屏”与系统返回键均恢复进入前的屏幕方向和系统栏。登录页面、平板模式及其他平台的网页布局没有改动。

## 模拟器验收

在 API 35、1080×2400 的 x86_64 模拟器上，从搜索结果打开 B 站视频页，检查标题换行、播放器宽度和评论；连续下滑后未再出现覆盖评论的巨大悬浮视频。进入横屏全屏后，播放器占据屏幕可用区域；退出按钮和系统返回键均回到竖屏，状态栏与导航栏恢复。Release 包从页面下方进入全屏再退出后，仍停留在此前滚动位置附近。Android 首次使用沉浸模式可能显示系统提示。

以上为模拟器视觉与交互验收。用户真机、不同 B 站视频页类型及平台后续网页改版仍需复测；不能据此推断所有官方电脑网页均已适配手机。
