# OpenScope Android 0.4.7 本地验收

0.4.7 修复知乎和抖音官方电脑网页在“手机页面”设置下的横向裁切。知乎首页原有约 1032 CSS 像素的双栏内容被重排为单列，卡片标题、摘要和互动栏按手机宽度换行；发想法区域的“同步到圈子”也不再挤成竖排。抖音原页约 628 CSS 像素的最小宽度被解除，精选信息流改为单列；独立 `/video/` 页原本至少 852 CSS 像素的播放器及详情收进手机视口。视频信息流弹层和独立页均保留官方页面及原有账号会话。

抖音视频页新增与 B 站一致的 App 顶部“全屏”入口：切换横屏并隐藏系统栏，退出按钮或系统返回键恢复竖屏。独立视频页在横屏时把播放器铺满 WebView；信息流弹层使用官方播放器的横屏布局。上述样式仅注入非登录的手机页面；官方登录页和平板页面不使用这些规则。

## 模拟器验收

在 API 35、1080×2400 的 x86_64 模拟器中，使用已保存的会话打开知乎首页，浏览器文档宽度与视口同为 412 CSS 像素，首页卡片、摘要、互动栏和发想法区域均能完整显示。打开抖音精选页，单列卡片图像与标题完整；进入视频弹层，画面、右侧操作区和底部控制条可见。直接打开 `/video/7672763194405817663`，播放器、标题、互动量均位于视口内；横屏全屏时视频按比例居中播放，退出按钮恢复 412 CSS 像素竖屏视口，并保留视频页。两种抖音视频入口都已进行横屏目视检查。

此验收不覆盖目标真机、不同屏幕比例、全部知乎文章类型或抖音直播/图文页；平台后续 DOM 改版可能需要更新适配选择器。视频音频受 WebView 媒体权限和平台策略影响，不以本次排版测试证明音频可用。
