# OpenScope Android 0.4.3 本地验收

日期：2026-09-23。工作目录 `D:\OpenScope`；这是 0.4.2 公开版之后的本地开发版本，未作为 GitHub Release 发布。

## 本轮变化

- 普通搜索首页移除右上角重复的“账号”按钮，底部账号入口保留。
- 当 Bilibili、知乎、小红书、抖音四个来源都由 App 确认为已登录时，“你的内容来源”自动收成右侧的“内容来源 · 已连接 4/4”；点按可展开，展开后可再收起。只要有来源未确认登录，仍显示完整账号入口。
- 设置新增持久化的“极简首页”。开启后，空白搜索首页只显示居中的 OpenScope、搜索栏和**单行排列**的四个平台标识；结果页仍按原布局呈现。点按 OpenScope 标题可进入设置并关闭该模式。
- 小红书热搜选项改为读取官方 Explore 网页自身加载的热词，不向小红书接口发无签名直连请求，也不自动处理验证码。没有热词时显示不可用状态并提供官方页面入口。

## 已验证与边界

API 35 x86_64 模拟器上，极简模式仅显示品牌、搜索框和单行四个平台；点按品牌可进入设置。截图见 [极简首页](images/openscope-minimal-043.png)。未登录的小红书官方页面只显示登录引导，因此热词不可用，App 显示提示与官方页面入口，见 [回退界面](images/openscope-xhs-hot-fallback-043.png)；**已登录的热词返回仍待目标设备验证**。四个平台全部登录后的自动收起逻辑已实现，当前模拟器缺少三个有效会话，尚未做真实四账号视觉验收。
